# Customer Churn Analysis

Exploratory data analysis on telecom customer data (7,043 records) using Python, Pandas, and Matplotlib/Seaborn to identify key drivers of customer churn.

# Key Findings
- Overall churn rate: 26.5%
- Month-to-month contracts churn far more (43%) than two-year contracts (3%)
- Most churn happens in the first few months of tenure
- Fiber internet users churn more (42%) than DSL users (19%)
- Customers without Online Security/Tech Support churn 2–3x more
- Electronic check users churn the most (45%); automatic payments churn least (~15–17%)
- Senior citizens churn almost 2x more than younger customers

# Recommendations
- Incentivize longer contracts over month-to-month plans
- Strengthen early onboarding to reduce first-month drop-offs
- Review fiber service quality/pricing
- Bundle security & support add-ons to boost retention
- Encourage automatic payment methods over electronic checks

# Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
